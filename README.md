# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 操作日志与版本恢复

- **自动入账**：字模新增 / 修改 / 移除，版面落字 / 替换 / 起字 / 清空，草稿保存 / 载入 / 删除，导出图片，都会记录为带时间和前后状态（字模 + 版面快照）的操作记录。
- **筛选与浏览**：日志可按字模、版面、草稿、导出、恢复分类筛选，按时间正序 / 倒序浏览。
- **记录对比**：任选两条记录，可对比字模数量差异（种数、枚数、新增 / 移除 / 数量变化）和版面落字差异（落字数、逐格增删替换）。
- **版本恢复**：可将字模库与版面恢复到任意一条记录时的状态，只回滚字模与版面，草稿、纸张设置与日志不受影响；恢复本身也会入账，且可一键「撤销最近一次恢复」。
- **冲突保护**：目标版本与当前其他数据冲突时（如落字超出当前纸张网格、已存草稿引用了目标版本中没有的字模），会明确提示原因并拒绝恢复。
- **本地持久化**：操作记录、当前字模与版面、恢复结果都保存在 localStorage，刷新后保留。
